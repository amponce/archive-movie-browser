Ask your assistant what to watch.

The film catalogue behind this site now speaks MCP. Connect it to Claude, Cursor or any MCP client, and it can search tens of thousands of public-domain films on the Internet Archive and hand back links that play.

  • “Find me a film noir from the 1940s that runs under ninety minutes.”
  • “What Buster Keaton films can I watch tonight, free and legal?”
  • “Which film is this Archive upload, really: dead_people_ipod?”

That last one is Messiah of Evil (1975). Archive.org titles are messy; the server knows which real film hundreds of the most-watched uploads are, with year and poster.

What it can do

ToolWhat it does
search_filmsSearch by title, subject or creator across every collection at once. Re-uploads of the same film are collapsed into one.
browse_filmsList a collection by genre and decade, sorted by popularity, rating, release date or title.
get_filmEverything about one upload: description, length, genres, and the real film it is, if known.
list_collectionsThe collections, genres, decades and sort orders the other tools accept.

Every film comes back with a link that plays on this site, the Archive.org page, and an embed URL. No API keys, no account.

Try it now

Nothing to install. The server is hosted here, free and read-only:

https://archive-movie-browser.vercel.app/api/mcp

In Claude, open Settings, then Connectors, choose Add custom connector and paste that address. In Claude Code:

claude mcp add --transport http archive-movies https://archive-movie-browser.vercel.app/api/mcp

In Cursor and most other clients, add it to the MCP settings file:

{
  "mcpServers": {
    "archive-movies": { "url": "https://archive-movie-browser.vercel.app/api/mcp" }
  }
}

It is a shared endpoint: 40 requests a minute per address, and answers are cached for 15 minutes. For heavier use, run your own copy.

Run your own copy

  1. You need Node.js 22 or newer.
  2. Get the code and install the server's two dependencies:
git clone https://github.com/amponce/archive-movie-browser.git
cd archive-movie-browser/mcp && npm install
  1. Tell your assistant where it is. In Claude Code:
claude mcp add archive-movies -- node /absolute/path/to/archive-movie-browser/mcp/server.mjs

In Claude Desktop, Cursor and most other clients, add this to the MCP settings file:

{
  "mcpServers": {
    "archive-movies": {
      "command": "node",
      "args": ["/absolute/path/to/archive-movie-browser/mcp/server.mjs"]
    }
  }
}

Then ask it for a film. The README has the details and how to run the tests.

Help build it

The server is new and small on purpose. A one-line npx install, a hosted HTTP endpoint, a recommendation tool and a “movie night” prompt are all open issues, written up and ready for someone to take. It is MIT licensed, like the rest of the project.
