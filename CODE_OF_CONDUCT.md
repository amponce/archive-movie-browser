# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, give and take feedback gracefully, and keep the focus on making the project better. Harassment, personal attacks, and discriminatory language are not acceptable in issues, pull requests, reviews, or anywhere else connected to this project.

To report a problem, email the maintainer privately: the address is under [Contact](https://www.orphanedfilms.com/takedown#contact) on the site. Reports are kept confidential.
